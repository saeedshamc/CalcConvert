# CalcConvert

CalcConvert is a clean Flutter app for everyday unit conversions. It currently supports:

- Length conversions
- Weight conversions
- Temperature conversions

## Getting started

1. Install Flutter SDK.
2. Run `flutter pub get`.
3. Start the app with `flutter run`.

## Project structure

- `lib/main.dart` – app UI and conversion logic
- `test/widget_test.dart` – basic widget smoke test
- `android/` – Android project configuration
